# O-Ink para KDE Plasma 6

Tema global no estilo de [ownaka.net](https://ownaka.net): tinta bege sobre papel escuro, Commit Mono e cantos retos.

![preview](plasma/look-and-feel/net.ownaka.oink/contents/previews/fullscreenpreview.jpg)

## O que vem incluso

- Tema global (look-and-feel) `net.ownaka.oink` + splash
- Tema do Plasma `o-ink`
- Decoração de janelas Aurorae `O-Ink`
- Esquema de cores `OInk`
- Ícones `O-Ink`
- Papel de parede `O-Ink`
- Perfil e esquema de cores do Konsole
- `extras/O-Ink.theme.css` — tema para Vencord (Discord)

## Instalação

```bash
git clone https://github.com/ownaka/plasma-o-ink.git
cd plasma-o-ink
./install.sh --apply
```

Sem `--apply` os arquivos são só copiados; aplique depois em
**Configurações do Sistema → Tema Global → O-Ink**.

Fonte recomendada: [Commit Mono](https://commitmono.com).

Vencord: copie `extras/O-Ink.theme.css` para `~/.config/Vencord/themes/`.
